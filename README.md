# Rajendra's Portfolio

A modern, responsive, and highly interactive personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion. 

## Features

- **Next.js (App Router)**: Fast, optimized, and SEO-friendly routing.
- **React**: Component-based architecture for an interactive UI.
- **Tailwind CSS**: Utility-first CSS framework for rapid and highly customizable styling.
- **Framer Motion**: Smooth, high-performance animations and transitions, including interactive background canvas effects.
- **Lucide React**: Beautiful and consistent iconography.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.
- **TypeScript**: Strictly typed codebase for better maintainability and error catching.

## Tech Stack

- **Framework**: Next.js (v14)
- **Library**: React (v19)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

First, make sure you have Node.js installed, then clone the repository and install the dependencies.

### Installation

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### Running the Development Server

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `src/app/page.tsx` or components in `src/components/`. The page auto-updates as you edit the file.

## Project Structure

- `src/components/`: Reusable UI components and specific page sections (e.g., Hero, About, Contact).
- `src/data/`: Static content configuration (e.g., `siteConfig`, `heroRoles`).
- `public/`: Static assets such as images, fonts, and resume.
